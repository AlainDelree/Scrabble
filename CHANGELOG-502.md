# Changelog — Issue #502

## Dépendances

- **`requirements.txt` figé aux versions du build Windows v15, test de non-régression ajouté (issue #502).**
  - Les 21 paquets (directs et transitifs) relevés au build v15 (issue #501) sont désormais chacun épinglés à une version exacte (`==`) : `altgraph`, `bottle`, `cffi`, `clr_loader`, `colorama`, `iniconfig`, `packaging`, `pefile`, `pluggy`, `proxy_tools`, `pycparser`, `pygments`, `pyinstaller`, `pyinstaller-hooks-contrib`, `pytest`, `pythonnet`, `pywebview`, `pywin32-ctypes`, `setuptools`, `spylls`, `typing_extensions`.

Identification faite par double lecture sans aucune installation : absence du paquet dans l'environnement Python Linux `~/Scrabble/venv` (import échoué), recoupée avec les marqueurs de dépendance déjà déclarés dans les métadonnées des paquets déjà installés dans cet environnement (`importlib.metadata`), pour `pyinstaller` (`pefile`, `pywin32-ctypes` en `sys_platform == "win32"`), `pywebview` (`pythonnet` en `sys_platform == "win32"`) et `pytest` (`colorama` en `sys_platform == "win32"`). `colorama` apparaissait présent dans cet environnement via un paquet système (`apt`, hors pip) sans rapport avec le projet ; la lecture de métadonnées de `pytest` lève le doute en sa faveur du marqueur.
  - Commentaires existants sur `pythonnet` (issues #411 et #412) conservés et réécrits pour la nouvelle syntaxe `==3.2.1`. Commentaire de tête ajouté : versions figées au relevé du build v15, mise à jour volontaire uniquement.
